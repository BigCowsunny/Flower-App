# เว็บแอปจำแนกดอกไม้ (ทำงานในเครื่อง)

เว็บแอป Streamlit ภาษาไทยสำหรับใช้ EfficientNetB0 ทำนายภาพเป็นค่าเริ่มต้น หรือเลือกโมเดลที่ติดตั้งไว้จากเมนูเลือกโมเดล เช่น EfficientNetB0, MobileNetV2 และ ResNet50 ทำงานในเครื่อง ไม่มีการฝึก/แก้โมเดล ไม่มีการสร้าง augmentation และไม่ส่งรูปไปบริการภายนอก รองรับ CPU

แอปใช้ `models/EfficientNetB0/EfficientNetB0.keras` เป็นค่าเริ่มต้น เมนู “เลือกโมเดล” แสดงตัวเลือกตามไฟล์โมเดลที่มีใน `model_root` และใช้ภาพอัปโหลดทำนายด้วยรุ่นที่เลือก ส่วน `models/class_mapping.json` ใช้ร่วมกันทุกโมเดล การตรวจ pipeline เดิมยืนยัน 10 คลาส ลำดับตาม mapping และ input RGB 224×224 ช่วง 0–255

แต่ละโมเดลอ่านไฟล์ชื่อเดียวกับรุ่น: `<model_root>/MobileNetV2/MobileNetV2.keras`, `<model_root>/ResNet50/ResNet50.keras` และ `<model_root>/EfficientNetB0/EfficientNetB0.keras`

## ความต้องการ

- Windows 64-bit และ Python 3.12 64-bit (ติดตั้งจาก python.org และเลือกเพิ่ม Python ลง PATH หรือใช้ Python Launcher)
- พื้นที่ดิสก์สำหรับ TensorFlow และ virtual environment หลาย GB
- CPU ใช้งานได้ ไม่ต้องมี NVIDIA GPU หรือ CUDA

## ติดตั้ง

เปิด PowerShell ในโฟลเดอร์โครงการ:

```powershell
cd C:\path\to\Flower-App
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

TensorFlow รุ่นใหม่บน Windows ใช้ CPU เป็นค่าเริ่มต้น (การรองรับ GPU บน Windows โดยตรงหยุดที่ TensorFlow 2.10) ไม่ต้องติดตั้ง CUDA สำหรับแอปนี้

## ตั้งค่า path โมเดล

ค่าเริ่มต้นใน `config/settings.json` ใช้ `models` ซึ่งชี้ไปยังไฟล์โมเดลและ mapping ที่รวมมากับโครงการ หากเก็บโมเดลไว้นอกโครงการ ให้แก้ `model_root` เป็น path ของโฟลเดอร์นั้น เช่น:

```json
{
  "model_root": "models",
  "image_size": [224, 224]
}
```

ใช้ `/` หรือ escape `\\` ใน JSON ได้ รองรับ path ภาษาไทยและช่องว่าง ตัวอย่างโครงสร้างที่คาดหวัง:

```text
<model_root>/class_mapping.json
<model_root>/EfficientNetB0/EfficientNetB0.keras
```

ไม่ต้องคัดลอกโมเดลมาไว้ในโครงการก็ได้ หากต้องการเก็บโมเดลนอกโฟลเดอร์โครงการ ให้แก้ path ในไฟล์ตั้งค่า

## เปิดและปิด

ใช้ไฟล์ `run_app.bat` หรือสั่ง:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address localhost --server.port 8501
```

เปิด `http://localhost:8501` ในเบราว์เซอร์ ปิดเซิร์ฟเวอร์ด้วย `Ctrl+C` ในหน้าต่าง terminal

## วิธีใช้

เมื่อเข้าเว็บจะพบหน้า “ยินดีต้อนรับสู่ Flower APP” เมนูด้านล่างมี 4 ส่วน: หน้าหลัก, อัปโหลดภาพ, สแกนด้วยกล้อง และเลือกโมเดล หน้าอัปโหลดใช้ EfficientNetB0 เป็นค่าเริ่มต้น ส่วนหน้าเลือกโมเดลแสดงรุ่นที่ติดตั้งไว้ (เช่น EfficientNetB0, MobileNetV2 หรือ ResNet50) และให้อัปโหลดภาพหนึ่งภาพหรือหลายภาพเพื่อทำนายด้วยรุ่นที่เลือก โดยแต่ละรุ่นอ่านไฟล์ชื่อเดียวกับรุ่น ภาพของแต่ละหน้าอัปโหลดเก็บแยกกัน และยังอยู่เมื่อสลับเมนู

อัปโหลด JPG/JPEG/PNG/WebP ได้สูงสุด 20 ภาพ หรือกด “สแกนด้วยกล้อง” เพื่อเชื่อมต่อกล้อง ถ่ายภาพแล้วตรวจดูภาพตัวอย่าง กดยืนยันใช้ภาพนี้ก่อนจึงจะนำไปทำนาย (หรือกดถ่ายใหม่) หน้าอัปโหลดและสแกนกล้องใช้ EfficientNetB0 ส่วนหน้าเลือกโมเดลให้เลือกโมเดลที่จะทำนาย ไฟล์ละไม่เกิน 10 MB และภาพไม่เกิน 40 ล้านพิกเซล ผลแสดงชื่อดอกไม้ ความมั่นใจ ชื่อวิทยาศาสตร์ คำอธิบาย และความสำคัญทางพุทธศาสนา

การถ่ายภาพต้องอนุญาตกล้องในเบราว์เซอร์ก่อน ภาพที่ถ่ายจะถูกประมวลผลในแอปบนเครื่องเช่นเดียวกับภาพที่อัปโหลด และจะไม่เข้าคิวทำนายจนกว่าจะกดยืนยันภาพ

ภาพจะอยู่ในหน่วยความจำระหว่างการทำงาน และไม่มีการบันทึกถาวรโดยแอป มีการแก้ทิศ EXIF, แปลง RGB และ resize ด้วย TensorFlow bilinear antialias เป็น float32 ช่วง 0–255 โมเดลมี ImageNet preprocessing อยู่ภายใน จึงไม่หาร 255 หรือเรียก `preprocess_input` ซ้ำ

## ข้อจำกัดและแก้ปัญหา

- โมเดลทำนายได้เฉพาะ 10 คลาสใน `class_mapping.json` ภาพที่ไม่ใช่ดอกไม้หรืออยู่นอกกลุ่มก็อาจถูกจัดเข้าหนึ่งในคลาสเหล่านี้ ระบบยังไม่ได้ทดสอบการตรวจจับภาพนอกกลุ่ม
- ค่าความมั่นใจมาจาก softmax ไม่ใช่ Accuracy และไม่ใช่ความน่าจะเป็นที่ผ่าน calibration
- ข้อมูลพุทธศาสนาให้ความสำคัญกับหลักฐานเฉพาะของบัว/มะลิ และใช้คำอธิบายเรื่องการถวายดอกไม้กับอนิจจังเป็นบริบททั่วไปสำหรับชนิดอื่น ไม่ได้อ้างว่าทุกชนิดมีสัญลักษณ์เฉพาะ
- หากหน้าเว็บแจ้งไม่พบไฟล์ ให้ตรวจ `model_root` และชื่อโฟลเดอร์/ไฟล์ตามตัวอย่าง
- หากโหลดโมเดลไม่สำเร็จ ให้ใช้ Python 3.12 64-bit และติดตั้งใหม่ด้วย `pip install -r requirements.txt`; ดูรายละเอียด error ในหน้าเว็บ/terminal
- หากหน่วยความจำไม่พอ ให้ลดจำนวนภาพและปิดโปรแกรมอื่นก่อนเริ่มทำนาย
- หากพอร์ต 8501 ถูกใช้ ให้ปิดเซิร์ฟเวอร์เดิมก่อนเปิดใหม่

## สถานะการตรวจสอบ

ตรวจการเปลี่ยนเมนู หน้าต้อนรับ การเก็บภาพเมื่อสลับหน้า การแยกแหล่งภาพอัปโหลด/กล้อง และการล้างข้อมูลด้วย Streamlit AppTest แล้ว รวมถึงเปิดหน้าหลัก หน้าอัปโหลด และหน้ากล้องผ่านเบราว์เซอร์ที่ localhost จริง การตรวจนี้ไม่ได้รวมการทำนายภาพใหม่หรือการถ่ายภาพจากกล้องจริง

ทดสอบโหลดและทำนายด้วยไฟล์ชื่อเฉพาะรุ่นทั้งสามแล้ว ทั้งหมดรับภาพ 224×224×3 และส่งออก 10 คลาส แอปจะตรวจ input/output shape และจำนวนคลาสกับ mapping ก่อนใช้ไฟล์โมเดล

เมนูเลือกโมเดลทำนายด้วยโมเดลที่เลือกทีละรุ่นต่อการทำนายหนึ่งครั้ง ส่วนหน้าอัปโหลดภาพและสแกนกล้องยังใช้ EfficientNetB0 เป็นค่าเริ่มต้น การทดสอบกล้องจริงต้องอนุญาตกล้องในเบราว์เซอร์ก่อน การเทียบความมั่นใจกับ Colab สำหรับภาพเดียวกันยังไม่มีผลอ้างอิงรายภาพที่เก็บไว้ในเครื่อง
